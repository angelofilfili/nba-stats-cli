# NBA Stats CLI

A command-line tool that lets you search real-time NBA player stats using the NBA API.

## Features
- Search any NBA player's current season stats
- Compare two players side by side
- Displays points, rebounds, assists, steals, blocks, minutes, FG%, and 3P%

## How to Run
1. Clone the repo
2. Install dependencies: `py -m pip install nba_api`
3. Run: `py main.py`

## Built With
- Python
- nba_api
- Object Oriented Programming (OOP)

## What I Learned
I learned how to use an API to gather large amounts of information and to use it to create a fully functional script.
I also learned how to use the NBA API specifically.
I learned how to work with OOP, modules, APIs, dictionaries, lists, functions, and conditionals.
The biggest challenge for me was navigating nested JSON data from the API and figuring out how to match headers to row values to extract specific stats.
I had a difficult time conceptualizing how to use this API and how to work with it since it was a lot of information (there are a lot of NBA players).
